# Font asset notice

The project-level MIT license applies to the source code, not automatically to
the SHX files in this directory. The repository currently does not contain
authoritative provenance or redistribution terms for every font. Before
publishing a wheel, container, mirror, or commercial distribution containing
these files, the distributor must verify the license of each selected font or
replace the collection with assets they are authorized to redistribute.

Runtime deployments may keep fonts outside the package and point the reader to
them with the `DWG_READER_FONT_DIR` environment variable.
